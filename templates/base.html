Java Syntax Guide

Java is a class-based, object-oriented programming language. Here are the basic syntax rules:

  • All code must be inside a class
  • Class names should start with an uppercase letter
  • Method names should start with a lowercase letter
  • Curly braces {} define the beginning and ending of a block of code
  • Semicolons ; terminate statements
  • Java is case-sensitive
Basic Structure:
public class ClassName {
   public static void main(String[] args) {
       // Your code here
   }
}

for (int i = 0; i < 5; i++) {
   System.out.println("Count: " + i);
}

Simple Calculator
import java.util.Scanner;

public class Calculator {
   public static void main(String[] args) {
       Scanner scanner = new Scanner(System.in);
       
       System.out.print("Enter first number: ");
       double num1 = scanner.nextDouble();
       
       System.out.print("Enter second number: ");
       double num2 = scanner.nextDouble();
       
       System.out.println("Sum: " + (num1 + num2));
       System.out.println("Difference: " + (num1 - num2));
       System.out.println("Product: " + (num1 * num2));
       System.out.println("Quotient: " + (num1 / num2));
       
       scanner.close();
   }
}
Array Example
public class ArrayExample {
   public static void main(String[] args) {
       // Create an array of integers
       int[] numbers = {10, 20, 30, 40, 50};
       
       // Print all elements
       for (int i = 0; i < numbers.length; i++) {
           System.out.println("Element at index " + i + ": " + numbers[i]);
       }
   }
}

Debugging Tips

Common Errors and Solutions
  • Semicolon expected: Forgot to add ; at the end of a statement
  • Cannot find symbol: Misspelled a variable or method name
  • Class names must start with uppercase: Naming convention violation
  • Reached end of file while parsing: Missing closing brace }
  • Exception in thread "main": Runtime error, often caused by invalid operations
Debugging Techniques
  1. Read the error message carefully
  2. Check line numbers mentioned in error
  3. Use System.out.println() to print variable values
  4. Verify all braces are properly matched
  5. Ensure all statements end with semicolons
  6. Check for typos in variable/method names
